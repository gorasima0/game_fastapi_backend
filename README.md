# game_fastapi_backend
It`s an example of project.

For using this application, firstly we need to create virtual enviroment (.venv)

# python -m venv .venv

Secondly, activate this VENV

# .venv/Scripts/acitvate

Third, install FastAPI

# pip install FastAPI

And Uvicorn

# pip install uvicorn

Finaly, start it.

# uvicorn main:app --reload
